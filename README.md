# ضغط PDF + OCR عربي — Browser-only Arabic OCR & PDF Compressor

حوّل **PDF الممسوح (سكان) أو الصورة** إلى **PDF مضغوط وقابل للتحديد والنسخ والبحث** بالكامل داخل المتصفح.
لا خادم، لا مفاتيح API، ولا رفع للملفات: كل شيء يعمل على جهازك.

**Live demo:** https://nhadalqysy985-oss.github.io/ocr-pdf/

## ما تفعله الأداة

1. **تقرأ الصفحات** من PDF (عبر PDF.js) أو من الصور (JPG/PNG/WebP…)، وتنظّفها: رمادي + تمديد تباين (1%–99%) + خيار ثنائي Otsu.
2. **تعدّل ميل الصفحة** تلقائياً (±5°) بطريقة تباين إسقاط الصفوف مع تدوير حقيقي للصورة.
3. **تشغّل OCR عربي داخل المتصفح** (Tesseract.js + tessdata_fast) وتستخرج الطبقة النصية لكل صفحة.
4. **تضغط صورة كل صفحة** وتُعيد ترميزها ثم تدمج الصفحات في **ملف PDF واحد**: نفس شكل الصفحة ومقاسها الأصلي + **طبقة نص مخفية**، فيبدو كما هو ويُبحث فيه ويُنسخ منه.
5. **تنزيل PDF أو TXT أو نسخ النص** مباشرة.

## الضغط (الميزة الأساسية)

تولّد Tesseract صفحة PDF تحوي صورة الصفحة وطبقة النص المخفية. الأداة تستبدل صورة الصفحة داخلها بصورة مضغوطة (بنفس هندسة الصفحة، والطبقة النصية تبقى كما هي حرفياً)، ثم تدمج الصفحات:

| المستوى | ترميز الصورة | الدقة (الضلع الأطول) | JPEG | الناتج على العيّنة (صفحتان) |
|---|---|---|---|---|
| **أقصى ضغط** | 1‑بت Flate (DeviceGray) | 1600 px | — | **24 ك.ب** من 1006 ك.ب (**−98%**) |
| **متوازن** (افتراضي) | JPEG / DCTDecode | 2000 px | 66% | **171 ك.ب** (**−83%**) |
| **جودة عالية** | JPEG / DCTDecode | 2800 px | 82% | **519 ك.ب** (**−48%**) |
| **مخصص** | JPEG أو 1‑بت | 1200–3600 px | 30–95% | حسب الاختيار |

- الصورة المرئية في PDF هي الصفحة **بعد** التنظيف وتصحيح الميل، لذلك يظهر الناتج مستقيماً ونظيفاً.
- الصورة المُرمّزة تُكتب كـ XObject حقيقي: `DCTDecode` (JPEG) أو `FlateDecode` + `DeviceGray` + `BitsPerComponent 1` (أبيض/أسود)، وليس إعادة ترميز RGB منتفخة.
- **ضغط سريع بدون OCR**: ينتج PDF صوراً مضغوطاً في ثوانٍ (بدون طبقة نص).
- شريط النتيجة يعرض: الحجم قبل/بعد ونسبة التوفير، وحجم كل صفحة أثناء المعالجة.
- إن كان الملف المرفوع يحتوي أصلاً نصاً رقمياً (وليس مسحاً) تظهر **ملاحظة تحذيرية**، لأن المعالجة ستحوّله إلى صورة.

## الخصوصية

لا يوجد أي خادم. تُقرأ الملفات عبر File API، وتُرسم على canvas محلي، ويعمل Tesseract داخل Web Worker. جميع المكتبات وبيانات اللغة والـ WASM تُقدَّم من نفس الأصل (`vendor/`)، لذا يعمل التطبيق **بدون إنترنت** بعد التحميل الأول (بانتظام: بيانات اللغة تُخزَّن في IndexedDB).

## خط المعالجة

1. **العرض**: كل صفحة PDF عبر PDF.js (`scale = 3` افتراضياً، بحد 4500 px للضلع الأطول)، والصور عبر `createImageBitmap`.
2. **التنظيف**: رمادي ← تمديد تباين 1%/99% ← Otsu اختياري.
3. **تصحيح الميل**: تقدير الزاوية بتباين إسقاط الصفوف (−5°…+5°، خطوة 0.1°) وتدوير الصورة.
4. **الاعتراف**: `worker.recognize(canvas, {}, { pdf: true, text: true })` → صفحة PDF فيها الصورة + طبقة نص، ونص منطقي.
5. **الضغط**: قص الصورة إلى الدقة المختارة، ترميزها JPEG أو 1‑بت Flate، ثم **استبدال XObject الصورة** داخل صفحة Tesseract (مع حذف الصورة الأصلية من ملف التعريف) — الطبقة النصية لا تُمس.
6. **الدمج**: pdf-lib `copyPages` مع الحفاظ على مقاس الصفحة الأصلي (A4 = 595×842 pt مثلاً).

## التشغيل محلياً

العمالة (Web Workers) تحتاج HTTP وليس `file://`:

```powershell
cd ocr-pdf
.\start.ps1                 # يفتح http://127.0.0.1:8765/
# أو
node serve.mjs 8765
# أو أي خادم ثابت آخر:
# python -m http.server 8000
```

## الدقة والقياس

على ورقة امتحان عربية مولّدة بجودة مسح (صفحتان A4، ميل +1.35°/−0.9°، ضجيج ماسح)، مقاسة على النص المستخرج من الملف الناتج:

| الوضع | دقة الأحرف | دقة الكلمات | كلمات البحث | الحجم |
|---|---|---|---|---|
| متوازن (JPEG 2000/66%) | **98.63%** | 94.19% | 10/10 | 171 ك.ب |
| أقصى ضغط (1‑بت 1600) | **98.63%** | 94.19% | 10/10 | 24 ك.ب |
| جودة عالية (JPEG 2800/82%) | **98.63%** | 94.19% | 10/10 | 519 ك.ب |
| ضغط بدون OCR | — | — | — | 166 ك.ب |

المدخل الأصلي: 1006 ك.ب. الأداة تحافظ على ترتيب الأحرف المنطقي داخل الطبقة النصية (ToUnicode)، ونتائج PDF.js تظهر بترتيب بصري كما هو معتاد في PDF.js (انظر `TEST-REPORT.md`).

اختبارات كاملة (Playwright + Chrome headless) في `TEST-REPORT.md`.

## حدود الاستخدام

- الهدف هو الصفحات **الممسوحة/الصور**؛ الملفات الرقمية التي تحتوي نصاً أصلاً تُحذَّر داخل الواجهة.
- ذاكرة المتصفح تحدّ عدد الصفحات الكبيرة (المعالجة تسلسلية وتُحرَّر كل صفحة بعد استخدامها).
- الخط اليدوي والخطوط الزخرفية والصور منخفضة الدقة خارج نطاق دقة `tessdata_fast`.
